From #knowledge

Two tools reviewed for our way of working

Take two parts, not the whole skill

Build verify loop skill (Maanas)

  • Safe: two text files with no scripts, no network calls and no hidden instructions. The commands it names all exist in swayu-app.
  • Already covered: write what done looks like, watch the test fail first, run the checks, never weaken a test, stop after a few tries.
  • Worth adding: the outcome quality judge. It uses a rubric, good and bad examples, and a check that it rejects a bad page before anyone trusts it. Only "must fix" findings block, and a fix may never add a fact. This fits OF4 reply drafts, which today are only checked for invented numbers and promises.
  • Use with care: a fresh reviewing agent on every round costs tokens. Keep it for changes before a push.
Do not add now

executor.sh

  • One open source gateway that puts many tools behind one connection, with allow, ask and block rules.
  • The connector decision of 4 November already dropped it for customer connectors. Its own research page says it is for internal agents only.
  • For our engineering work it adds a second place where logins live, outside 1Password. It also duplicates the tool connections we already have. It is connected here with zero integrations.
  • Its block rules have not been shown to stop a real call.
  • Look again if one place to set agent permissions across many tools becomes the need.
