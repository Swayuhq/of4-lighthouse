Lighthouse Connector Walkthrough

One inbox for a small business, reading and replying on Instagram and Facebook through Composio and Zernio behind one gateway. Everything below ran on real test accounts: the Instagram account priya_test_at and the Facebook Page Sujit Test Cafe, set up as Priya's Cake Shop.

The loop

A customer comments. A provider reads it through the gateway. The replies lead drafts an answer, and the gateway keeps that draft for the owner. The owner presses Send, and the gateway posts it through the provider set for that channel. Every call writes one ledger row.

Walk it through

  1. Replies are ready when the owner opens the inbox

    Each waiting message shows why it is near the top, a link to the comment on its platform, and a reply already written in the owner's voice. The replies lead wrote 17 drafts on its own after the channels were read. The checker stopped one that offered a refund the owner never offers.

  2. The owner edits and sends

    The owner edited one Instagram draft and pressed Send. The gateway recorded the approval, then posted through Zernio two seconds later. Instagram itself returns the reply, from the business account, with the owner's edit in it.

How each provider plugs in

Both providers sit behind one function shape: a channel, an action, and arguments in; one item shape out. Every item carries the platform's own id, so moving a channel from one provider to the other never counts a message twice.

Composio

  • One MCP endpoint. Each call runs a named tool, such as the Facebook comment reader, against the owner's login held in Composio.
  • Composio brings its own Meta app, which Meta has already reviewed. Lighthouse needs no Meta review of its own for this path.
  • Answers come back as Meta's own fields. The Page's own comments carry only the Page's name, so Lighthouse drops them by name.
  • Wired in Lighthouse: Facebook read and reply, Instagram read.

Zernio

  • A plain REST API with one key: accounts, then posts with comments, then the comments of each post, and reviews.
  • Each comment comes with its replies and an owner flag, and each post with its address on the platform.
  • A reply carries a retry key, so a retry after a lost answer cannot post twice.
  • Wired in Lighthouse: Facebook and Instagram read and reply, Google reviews read and reply.

Where each one falls behind

Composio

  • Meta gives it fewer author names on Facebook: 8 of 12, so a third of customers would read as “Someone”.
  • The read used here returns no replies and no owner flag, so an answer typed in the Facebook app looks unanswered and the count drifts.
  • WhatsApp is send only, so it cannot bring customer messages in. Its Google review tools are listed but untested.
  • Instagram replies are not yet wired or tested.

Where it leads: an already reviewed Meta app, 5 of 5 Facebook replies, and email in the same catalogue.

Zernio

  • Facebook replies are untested, and Google reviews are untested until a Business Profile is connected.
  • The owner sees Zernio's name on Google's consent screen.
  • The free plan stops at two connected accounts; a card was added to lift it.

Where it leads: every name, the owner's own replies, links to each comment, one REST shape for comments and reviews, and a retry key.
