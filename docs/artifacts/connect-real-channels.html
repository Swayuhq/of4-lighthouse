3 · One plate

How every part connects

The rule that keeps it clean

The owner's screens never touch the database or a platform. They only call the app's own routes. The backend lives in src/, behind /api. Every channel enters through its connector and nowhere else, so a new channel is one new adapter.

Where it runs, and why there are no containers yet

Two processes on the laptop: the app and a local Postgres. Docker would wrap two things that need no isolation from each other, so it adds a step and no safety. When Lighthouse moves into Swayu, it uses the product's own staging pipeline, which already deploys.

4 · Watching, for real

What happens every 30 seconds after the change

Pick live channelsOnly channels the owner connected and whose key still works.
Ask the platform"Anything newer than the last item I saw?" using the business's own key.
Read the shapeThe channel's adapter turns each item into one message. Bad items are dropped and counted.
Store onceMessage saved and the bookmark moved in one database step, so nothing is stored twice or skipped.
LabelReader agents mark it as a question, order, complaint, spam or thanks.
ShowThe inbox and counts line update. If the platform refused, the card turns red and the count reads unknown.

WhatsApp works the other way round. Meta calls Swayu when a message arrives, so it needs a public web address. That means installing a tunnel tool, which is audited before install.

7 · Order of work

Build order

Build

  • Sign up, connect list and channel cards: three different versions of the connect screen, one chosen
  • Connect route for Instagram and Facebook, key encrypted in the connection table
  • Watcher: every 30 seconds, live channels only
  • Every card says Live or Sample, so sample data can never pass as real
  • Then WhatsApp by webhook, after the tunnel tool audit

Not yet proven

  • Whether comments from people without an app role reach the app in development mode. Community reports say no
  • The exact comment fields Meta returns today. The current adapters were written without checking
  • Whether one Meta app covers Instagram login and Facebook login together, or needs two products set up separately
